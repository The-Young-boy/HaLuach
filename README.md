# הלוח

לוח מידע בתוך לוח הווידג'טים של Windows 11: זמני היום ותאריך עברי, שבת וחג, מזג אוויר, רדיו, לימוד יומי, שערי מטבע, תחבורה ציבורית, צבע אדום ועוד. כל כרטיס אפשר להזיז או להסתיר, ויש גם ווידג'טים נפרדים. נבנה על ה-API הרשמי של Windows App SDK (Feed Provider ו-Widget Provider).

אחות של [הפיד](https://github.com/The-Young-boy/HaFeed). אפשר להתקין את שתיהן באותו מחשב.

## דרישות

- Windows 11 22H2 (build 22621) ומעלה, עם לוח הווידג'טים.
- Windows App Runtime 1.6. המתקין מוריד אותו ממיקרוסופט אם חסר.
- הרשאת מנהל פעם אחת, בהתקנה.

## התקנה

1. מורידים את `HaLuach-Setup.cmd` מ-[Releases](https://github.com/The-Young-boy/HaLuach/releases/latest).
2. מריצים, "התקנה", "המשך" במסך ההסבר, ומאשרים את בקשת המנהל.
3. מפעילים מחדש אם המתקין מבקש. Win+W, ולוחצים על הלוגו של הלוח בסרגל הצד. בפתיחה הראשונה עולה אשף קצר: מיקום, שיטת זמנים, נוסח וכרטיסים.

התקנה בלי ממשק: `HaLuach-Setup.cmd /quiet`. קוד יציאה 0 = הותקן, 3010 = הותקן ונדרשת הפעלה מחדש, 1 = נכשל (פרטים ב-`%ProgramData%\HaLuach\setup.log`).

**עדכונים:** הלוח בודק את ה-Release האחרון שתי דקות אחרי שהוא עולה, ואחר כך כל 6 שעות. גרסה חדשה מותקנת ברקע, לא בשבת ובחג. אפשר לכבות ב"אודות".

**הסרה:** מריצים את אותו קובץ, "הסרה". החבילה והתעודה נמחקות, וקובץ המדיניות חוזר למקור. אם הפיד מותקן במחשב, קובץ המדיניות נשאר פתוח בשבילו.

אחרי עדכון גדול של Windows, קובץ המדיניות עלול לחזור למקור. אז מריצים את המתקין שוב.

## ווידג'טים

לכל כרטיס יש ווידג'ט נפרד שאפשר להצמיד ללוח. הם מתעדכנים גם כשהלוח סגור. ב"התאמה אישית" של ווידג'ט בוחרים מה הוא מראה: תחנה אחת, מקום אחר (זמנים, שבת, מזג אוויר), מטבע, לימוד, פורום, פודקאסט, משלוח, תאריך אישי או יישוב בצבע אדום. אפשר להצמיד כמה ווידג'טים מאותו סוג, כל אחד עם בחירה משלו.

## איך זה עובד

**הרשאה אזורית.** Windows פותח פידים של צד שלישי בלוח רק באזור EEA. המתקין מוסיף את קוד האזור של המחשב לשלושה כללים ב-`C:\Windows\System32\IntegratedServicesRegionPolicySet.json`: פיד צד שלישי, כיבוי הפיד של מיקרוסופט, ופתיחת קישורים בדפדפן ברירת המחדל. עותק המקור נשמר ב-`.orig`. אין שינוי ב-hosts, אין תעודת Root, ואין שרת מקומי.

**החבילה.** MSIX חתום בתעודה עצמית. התעודה נכנסת ל-`LocalMachine\TrustedPeople` בלבד, כי Windows לא מתקין חבילה לא חתומה שמריצה exe.

**הספק.** `haluach-widget.exe` הוא שרת COM מחוץ לתהליך (Rust). הלוח טוען את `https://the-young-boy.github.io/HaLuach/board/`, וכל בקשה בנתיב הזה מגיעה לספק, שעונה מתוך ה-exe. שום דבר לא מוגש מהכתובת עצמה. כל הבקשות לשירותים חיצוניים יוצאות מהספק, בלי שרת ביניים.
